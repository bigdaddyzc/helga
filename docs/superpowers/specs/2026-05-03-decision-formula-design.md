# 通用决策数学公式设计

**日期**: 2026-05-03
**项目**: HELGA (人文环境学习与生成代理系统)
**目的**: 为 HELGA 嵌入式代理推导出通用决策数学公式，输出概率分布，支持用户反馈强化学习

---

## 1. 设计目标

构建一个数学公式，满足以下条件：
- 输入：环境变量（时间/空间/社会/信息）、记忆状态
- 输出：层次动作的概率分布（意图层 + 实现层）
- 支持多轮对话（不确定性驱动，主动询问）
- 半参数化：核心公式可解释，部分参数可学习
- 强化学习：通过用户打分+理由更新模型

---

## 2. 整体架构

```
P(a | E, M) = Softmax(
    β · EU(a) + γ · Attention(E, M)
) ⊙ P_cultural(a | Z)
```

其中：
- `a` = 层次动作（意图 + 实现）
- `E` = 嵌套环境变量
- `M` = 记忆状态
- `EU(a)` = 期望效用
- `P_cultural(a | Z)` = 分层文化先验
- `Attention(E, M)` = 可学习注意力

---

## 3. 期望效用函数

```
EU(a) = Σ_k w_k · value_k(a) - λ · norm_cost(a) - η · complexity(a) - ψ · risk(a)
```

参数：
- `w_k`: 可学习的价值维度权重
- `λ`: 规范违反成本系数
- `η`: 复杂度惩罚系数
- `ψ`: 风险惩罚系数

价值维度：`value_k(a)` 衡量动作在各个价值维度上的贡献。

---

## 4. 分层文化先验

```
P_cultural(a | Z) = P_value(a | 价值观层) · P_norm(a | 规范层) · P_context(a | 情境层)
```

### 4.1 价值观层（顶层）

基于 Schwartz 10 类价值观：
- 自主、刺激、享乐
- 成就、权力、安全
- 顺从、传统、仁爱、普世

`P_value(a)` 表示动作在当前价值观取向下的先验倾向。

### 4.2 规范层（中层）

文化规范约束：
- 权力距离（PD）
- 不确定性规避（UAI）
- 个人主义/集体主义（IDV）
- 长期/短期导向（LTO）

`P_norm(a)` 衡量动作与文化规范的符合程度。

### 4.3 情境层（底层）

当前场景的具体规范：
- 会议礼仪、工作场所规范、社交礼仪等

`P_context(a)` 过滤明显不合理的动作。

## 5. 嵌套环境变量编码

```
E = { E_time, E_space, E_social, E_info }
```

### 5.1 时间维度

```
E_time = {
    current_time:     # 当前时间
    deadline_pressure: # 截止时间压力
    time_horizon:     # 时间视野
    duration:          # 预期持续时间
}
```

### 5.2 空间维度

```
E_space = {
    location_type:     # 场所类型（办公室、远程等）
    physical_context:  # 物理环境
    proximity:         # 物理距离
}
```

### 5.3 社会维度

```
E_social = {
    relationship_dynamics:  # 人际关系动态
    power_distance:         # 权力距离
    group_norm:            # 群体规范
    cultural_context:       # 文化背景
}
```

### 5.4 信息维度

```
E_info = {
    uncertainty:        # 信息不确定性
    confidence:        # 置信度
    information_quality: # 信息质量
    missing_key_info:  # 缺失关键信息标记
}
```

### 5.5 编码方式

嵌套结构通过 LLM/Embedding 独立编码后融合：
```
Encoded(E) = [ Enc(E_time); Enc(E_space); Enc(E_social); Enc(E_info) ] → R^d
```

## 6. 注意力机制

```
Attention(E, M) = Σ_i ω_i(E, M) · h_i(E, M)
```

其中：
```
ω_i = softmax( v^T · tanh(W_1 · [E; M] + W_2 · h_i) )
```

可学习的注意力权重，自适应地关注当前情境相关的环境因子。

---

## 7. 层次动作空间

决策分为两层：

### 7.1 意图层（高层）

```
P(intent | E, M) = Softmax( ... )
```

可选意图：
- `沟通` (communicate)
- `等待` (wait)
- `升级` (escalate)
- `询问` (ask) - 主动询问以获取信息
- `放弃` (abandon)

### 7.2 实现层（具体动作）

```
P(action | intent, E, M) = Softmax( ... )
```

每个意图对应多个具体实现：
- `沟通` → 发微信、发邮件、打电话、当面沟通
- `等待` → 等待5分钟、等待15分钟、等待更久
- `升级` → 告知上级、告知同事、公开问题
- `询问` → 澄清意图、补充情境、探询偏好
- `放弃` → 暂不处理、记录待办、委派他人

### 7.3 动作选择

```
a = (intent_id, action_id)
P(a) = P(intent) · P(action | intent)
```

## 8. 主动询问机制（关键扩展）

### 8.1 触发条件

```
Uncertainty = H(P(a | E, M))  # 熵作为不确定性度量

Ask_triggered = (Uncertainty > θ_ask) OR (Missing_key_info(E) == true)
```

当：
- 决策熵超过阈值（信息不足）
- 或存在缺失的关键信息

则触发询问。

### 8.2 询问模式

```
if Ask_triggered:
    intent = "ask"
    question = generate_question(current_belief)
    # 挂起决策，等待用户回复
    # 用户回复后，更新 E 和 M，重新进入决策循环
else:
    # 正常执行模式
    a = select_action(P(a | E, M))
```

### 8.3 意图澄清策略

询问聚焦于澄清用户意图：

```
Q_mapping = {
    "沟通": "你想通过什么方式与对方沟通？",
    "等待": "你愿意等待多长时间？",
    "升级": "你想升级给谁？",
    "放弃": "你想如何处理这个问题？"
}
```

## 9. 强化学习更新机制

### 9.1 用户反馈格式

用户同时提供：
- `score`: 单维度打分（1-5 分）
- `rationale`: 决策理由

### 9.2 损失函数

```
L_total = L_policy + α · L_supervised + β · L_contrastive
```

#### 9.2.1 策略损失（Policy Loss）

```
L_policy = -log P(a_chosen | E, M) · score
```

#### 9.2.2 监督损失（Supervised Loss）

```
L_supervised = Σ_user ||P_predicted - P_preferred||²
```

用户选择的决策作为监督信号。

#### 9.2.3 对比损失（Contrastive Loss）

```
L_contrastive = max(0, margin - sim(a_pos, a_neg) + sim(a_neg, a_pos))
```

用户理由用于构建偏好对：
- `a_pos`: 用户正向评价的动作
- `a_neg`: 用户负向评价的动作

### 9.3 更新流程

1. 模型输出概率分布 `P(a | E, M)`
2. 用户选择决策并打分 + 提供理由
3. 理由解析 → 构建 (positive, negative) 对
4. 计算 `L_total` 并更新参数：
   - `w_k`, `λ`, `η`, `ψ`（效用函数参数）
   - `W_1`, `W_2`, `v`（注意力权重）
   - 文化先验参数

## 10. 完整数学公式

```
P(a | E, M) =
    if H(P(a|E,M)) > θ_ask OR Missing_key_info(E):
        # 询问模式
        P_ask = Softmax( γ · Attention(E, M) ) ⊙ P_cultural(ask | Z)
        return P_ask
    else:
        # 执行模式
        P_exec = Softmax( β · EU(a) + γ · Attention(E, M) ) ⊙ P_cultural(a | Z)
        return P_exec

Where:
    EU(a) = Σ_k w_k · value_k(a) - λ · norm_cost(a) - η · complexity(a) - ψ · risk(a)

    P_cultural(a | Z) = P_value(a) · P_norm(a) · P_context(a)

    Attention(E, M) = Σ_i ω_i(E, M) · h_i(E, M)
    ω_i = softmax( v^T · tanh(W_1 · [E; M] + W_2 · h_i) )

    H(P) = -Σ_a P(a) · log P(a)  # 熵
```
